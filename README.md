# Bank Loan Analysis Dashboard

## Project Overview

This project analyzes bank loan applications, funding, repayments, customer characteristics, and loan quality using **Excel and Microsoft Power BI**.

The goal is to identify key trends and provide useful insights into loan applications, approvals, funding, repayment, and customer behavior.

## Objectives

- Analyze total loan applications.
- Measure approved, rejected, and pending applications.
- Calculate total funded and repaid amounts.
- Classify loans into Good Loan and Bad Loan categories.
- Analyze loan activity by region.
- Analyze applications by loan purpose and employment status.
- Examine monthly funding trends.
- Analyze customer credit scores and loan amounts.
- Visualize repayment and application status.

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- GitHub

## Dashboard Features

The Power BI dashboard includes:

- Loan application KPIs
- Loan quality distribution
- Application status analysis
- Repayment status analysis
- Applications by region
- Funded amount by region
- Amount repaid by region
- Average credit score by region
- Average loan amount by region
- Applications by loan purpose
- Applications by employment status
- Monthly loan funding trend

## Key Insights

- The dataset contains **600 loan applications**.
- **418 applications were approved**, while 121 were rejected and 61 remained pending.
- Total funded loans amounted to approximately **$15.54 million**.
- Approximately **$11.66 million** had been repaid.
- The dataset contains 210 Good Loans and 390 Bad Loans.
- The dashboard allows loan performance to be compared across regions, purposes, employment statuses, and time periods.
